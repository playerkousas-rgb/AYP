#  部署瘦身與防增肥規範（Vercel）

> 目的：防止 Vercel 儲存空間配額爆滿，同時**功能／UI／體驗 100% 零倒退**。
> 原則：人會忘記，機器不會 —— 所有規範都落在自動守門（`scripts/lint.js`、`scripts/check.js`、`scripts/build.js`），`npm run build` 失敗即擋下增肥。改規範＝改這三個檔＋在本文件落紀錄。

## 1. 部署管線（只上傳最終產物）

| 設定 | 值 | 作用 |
|---|---|---|
| `vercel.json → buildCommand` | `npm run build` | 先 lint＋check 再產 `dist/`，增肥直接擋在部署前 |
| `vercel.json → outputDirectory` | `dist` | **只上傳部署產物**，開發環境／測試／文件一律不進 CDN |
| `vercel.json → installCommand` | `npm install --omit=dev --no-audit --no-fund` | 生產建置**不裝 devDependencies**（jsdom 等只供本機測試） |
| `.vercelignore` | 見檔 | 上傳黑名單：`.git`、`node_modules`、`tests/`、`docs/`、`*.md`、備份檔、`uploads/` 等 |

- `dist/` 由 `scripts/build.js` 產生：**核心 5 檔＋assets/**，逐檔 sha256 校驗、禁止多餘檔案。
- 執行時依賴（`dependencies`）**永遠為零**——本站係純靜態 PWA，唔准加運行套件。

## 2. 圖片規範（AVIF／PNG 分工）

- 所有圖片放 `assets/`。守門預算：**單一 ≤ 120KB、assets 總和 ≤ 200KB**（`check.js` 強制）。
- **Icon 類以 PNG 為相容底、AVIF 優先**：iOS `apple-touch-icon` 與 manifest `maskable` 對 AVIF 支援不齊，**必須保留 PNG**；但 favicon（`index.html`）與 manifest `any` 採「AVIF 在前、PNG 回退」雙 link／雙 entry，支援 AVIF 嘅瀏覽器／平台自動食 AVIF 慳位。PNG 靠「去中繼＋調色盤／depth 8」壓瘦：
  ```bash
  convert in.png -strip -colors 256 +dither -define png:compression-level=9 out.png
  ```
- **頁內展示圖一律 AVIF＋PNG 回退**（`<picture>`，支援 AVIF 嘅瀏覽器自動揀 AVIF）：
  ```html
  <picture><source srcset="assets/x.avif" type="image/avif"><img src="assets/x.png" alt="…"></picture>
  ```
  產 AVIF：`convert in.png -quality 55 out.avif`（本倉 header logo 即範例：AVIF 1.9KB vs PNG 15KB）。
- **新增任何資產＝三連動**：① 在 `index.html`／`manifest.webmanifest` 引用；② 加入 `sw.js` 的 `ASSETS` 並**遞增 `CACHE` 版本號**（否則舊用戶食舊快取）；③ `check.js` 會雙向核對「被引用必存在／存在必被引用／sw 清單＝根檔案＋全部 assets」，漏任何一步 build 即紅。
- 高解析原稿（如 1024px 設計母檔）**唔入倉**；git history 係你嘅備份。

## 3. 防增肥預算（`scripts/check.js` 強制）

| 項目 | 上限 | 現值（2026-10-03） |
|---|---|---|
| 部署總和 | 400 KB | ≈ 292 KB |
| assets 總和 | 200 KB | ≈ 117.7 KB |
| 單一資產 | 120 KB | 最大 85.0 KB（logo-512.png） |

- 要調預算＝**刻意**改 `check.js` 常數＋更新本表＋落 changelog，唔准順手改。
- 禁入倉：`*.bak *.tmp *.old *.orig *.log *~`、`.DS_Store`、`uploads/`、`coverage/`（`.gitignore`＋`check.js` 雙保險）。
- `assets/` 入面**無人引用嘅檔＝死重**，check 直接失敗——杜絕「放低張圖忘記刪」。
- 未使用嘅 i18n 頂層鍵只出**警告**（現存：`langLabel`、`NEW_SYSTEM_NOTE`，屬內容儲備，刻意保留）。

## 4. 快取與更新（PWA）

- `vercel.json` headers：`/sw.js` 與 `/`、`/index.html` 用 `no-cache`／`must-revalidate`（保證更新即生效）；`/assets/*` 7 天＋`must-revalidate`；全站加 `nosniff`／`X-Frame-Options`／`Permissions-Policy`。
- `sw.js` 只快取 `res.ok` 嘅同源回應；離線回落永遠回有效 `Response`。

## 5. 出 RELEASE 前清單

1. `npm run lint && npm run check && npm run build && npm test`（102 項 DOM 回歸）。
2. 改過資產 → 遞增 `sw.js` 的 `CACHE` 版本。
3. `npm run preview` 本機睇一次 `dist/`。
4. 有瀏覽器環境先跑 Playwright（見 README；本沙盒 CDN 封鎖可跳過，以 jsdom 為準）。
