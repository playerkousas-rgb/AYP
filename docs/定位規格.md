## 4. 🆕 核心賣點一：童軍活動「直接對應／同步完成」AYP（你特別想加）

呢個係成隻 app 嘅**重中之重**。要清楚講：

### 4.1 同步完成方案（P95/2026 §六，8/15 試行）
| 童軍進度性獎章 | 同步完成 AYP |
|---|---|
| 考取 **「童軍高級獎章」** | 同步完成 **AYP 銅章** |
| 已完成 **AYP 銅章** → 透過 **「總領袖獎章」** | 同步完成 **AYP 漸進銀章** |

- 即係童軍成員日常進行童軍訓練／活動時，用**同一訓練、活動、紀錄及評核歷程**，同步完成童軍獎章同 AYP 章級，唔使重複做。
- 詳細對接內容、參加／紀錄／評核指引由童軍執行處網頁公布 —— app 會列出並附連結，並清楚標明「**需以官方最新公布為準**」。

### 4.2 直接對應概念（一般適用）
童軍活動／專科徽章／進度性獎章大多能滿足 AYP 各科全部或部分要求（服務科、技能科、野外鍛鍊科、康樂體育科、金章團體生活科），完成童軍訓練同時可申報 AYP，而毋須重複接受同一訓練／審核（**野外鍛鍊科旅程仍需由認可導師／評核員簽署**）。
- 官方有舊參照表（P103/2016）逐項列明，但**隨新綱要推行已更新**；app 會以「概念 + 最新官方對接指引」方式呈現，並附官方連結。

### 5.2 核心賣點二 = 「接駁／升團／轉處指南」（你之前特別想做的）

參考 repo「由 A 去到 B 要點做」嘅邏輯。要涵蓋（執行處轉換＋童軍支部升團都要、級別全覆蓋）：

| 場景 | 大致意思 | 想俾用家睇到 |
|---|---|---|
| **A. 由其他執行處接入童軍執行處** | 喺學校／其他制服團體執行處做緊 AYP，想轉入童軍 | 用 **FORM AYP/09**、要帶啲咩紀錄、經支部組長確認 |
| **B. 童軍支部升團** | 童軍 → 深資 → 樂行，AYP 同一執行處下點跟進 | 支部變咗 AYP 資格／紀錄簿點更新、同步完成有咩影響 |
| **C. 地域／旅團支部之間轉換** | 童軍內部由一個地域／旅團執行處支部轉去另一個 | 通知原屬及新屬執行處支部組長、更新所屬單位資料 |
| **D. 級別接駁** | 銅→銀→金（漸進）、直接銀／金、同步完成 | 每種情況點樣、有咩限制（年齡、紀錄簿、完成通知書）|
| **E. 半路轉處** | 喺 A 做咗一半，轉去 B 繼續 | 已批核科目／時數點算、點申報、邊啲唔可以帶住走 |

> ⚠️ 呢啲都係易出錯／會更新嘅操作細節，處理原則見 §7。

## 6. 分區結構草案

```
1) 開頭　　AYP 係咩？童軍成員點解／點樣考
2) 資格起步　誰合資格（含13歲特別安排）、揀銅/銀/金/同步完成

5) 加入童軍執行處　新手加入步驟（迎新講座/申請/紀錄簿）
6) 接駁指南 ★核心★　場景 A–E（互動揀情境）
7) 幾時起步時間表　幾歲做邊級最順
8) 完成之後　　領獎／證書／完成通知書
9) 表格＋辭典＋FAQ＋常見錯誤＋免責聲明
```

三級用 3 種顏色區分（銅啡／銀灰／金黃）；「同步完成」方案用特別標示。手機／平板／桌面都啱睇。
