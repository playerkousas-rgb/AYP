# AYP 童軍接駁指南：應用審查紀錄（2026-11-18）

審查日期：2026-11-18（香港時間）。延續 [2026-11-04 審查](2026-11-04-應用審查.md)，今次以「審核、完善、改進及建議」為目標，檢查程式行為、手機畫面、無障礙、資料安全及部署守門。本紀錄不代表官方確認內容。

## 審查方法

- 以 Chromium（headless）逐頁截圖檢查 390 px 手機及 1440 px 桌面：總覽、精靈、轉入、銜接、升團、其他、同步方案、銜接表、表格、查執行處、FAQ。
- 以 axe-core 自動檢查全部 11 個頁面的無障礙問題。
- 閱讀 `app.js` 主要流程：導覽、儲存、計算器日期、清除資料、複製報告。
- 執行 `npm run lint`、`npm run check`、`npm run build`、`npm test`（jsdom／Service Worker），以及 Playwright 瀏覽器回歸 22 項。

## 已修正

| # | 問題 | 影響 | 處理 |
|:--:|---|---|---|
| 1 | **手機「返回」鍵會直接離開 App**：切換頁面時沒有寫入瀏覽器歷史；重新載入亦一律回到總覽／精靈。 | 手機用家最常用的操作會令人以為 App 關閉；亦不能分享某一頁的連結。 | 每個頁面使用網址 hash（例如 `#bt-forms`、`#bt-sync`；總覽沒有 hash）。返回／前進會切換頁面；重新載入會留在原頁；直接連結會開啟指定頁面，首次瀏覽亦然。其他 hash（例如「跳至主要內容」）會被忽略。 |
| 2 | **沒有備份方法**：待辦、計算器進度、同步清單及考驗人員資料只存在目前瀏覽器。 | 換機、清除瀏覽資料或瀏覽器清理時資料會消失；入口閘門上線後，用家由其他網址開啟時亦讀不到舊資料。 | 「你在此裝置的資料」新增**匯出備份／匯入備份**。匯出會下載 `.json` 檔，並提示檔案可能包含個人資料。匯入會檢查檔案格式及每項數值，經確認後才取代現有資料；無效檔案不會改動現有資料。只讀寫現有儲存項目，不新增 localStorage key。 |
| 3 | 轉入頁的「較早活動」警告**在頁頂和卡片內各出現一次**，兩段內容一樣，上下相連。 | 重複內容令重點被淹沒，手機上要多捲一屏。 | 保留頁頂一次，移除卡片內的重複；測試改為檢查只出現一次。同步方案及銜接表屬獨立頁面，保留各自的警告。 |

## 建議及決定

### 用家決定（2026-11-18）

- **通告內容不再重新核對**：用家確認 AYP 通告很少修改，資料基準、同步完成試行細節及歷史銜接表維持現狀，不再作為待辦。
- **App 預計很少再改動**：因此不拆分 `data.js`。
- 手機頂欄及精靈「直接看總覽」兩項操作建議已實施，見上表第 8、9 項。

### 使用體驗（可選）

1. **emoji 作圖示**：部分卡片以 emoji（⏳、🗓️、🧮）作資訊圖示，讀屏軟件會讀出「沙漏」等字眼，舊 Android 亦可能顯示方框。建議逐步改用現有 SVG 圖示，或加上 `aria-hidden`。
2. **深連結推廣**：現在可以直接連到 `#bt-forms`（表格）、`#bt-sync`（同步方案）。如通告圖書館要連結相關工具，可指向這些網址（仍須經允許的入口，或使用已安裝的 PWA）。

### 技術及維護

3. **備份檔沒有加密**：已在介面及 README 說明。若日後要儲存更多個人資料，建議先評估是否需要密碼加密或縮減欄位。
4. **Vercel Web Analytics 與 hash 頁面**：視乎 Vercel 設定，hash 變化未必計作獨立頁面瀏覽；如需要分頁統計，請在 Vercel 後台確認。

## 驗證結果

- `npm run lint`、`npm run check`、`npm run build`：通過（check 保留兩項既有的未使用資料鍵警告）。
- `npm test`：DOM 107 項、互動 58 項、入口閘門模擬、Service Worker 18 項全部通過；新增的返回鍵及匯入測試連續執行 10 次均穩定通過。
- Playwright（Chromium headless）：22 項全部通過，包括返回鍵、直接連結、實際下載備份檔後清除再匯入還原。
- 頂欄及分頁列：360／390／430／1440 px、中英文均無橫向溢出，分頁文字沒有被截斷；axe 0 項違規。
- 以上均為本機模擬；**未做真機（iOS Safari／Android Chrome／已安裝 PWA）測試**。iOS 加入主畫面後的檔案下載及匯入流程，尤其需要真機確認。
