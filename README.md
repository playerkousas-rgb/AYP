# AYP 童軍接駁指南 / AYP Scout Bridging Guide

一個給香港童軍成員、領袖及執行處支部組長使用的**非官方**雙語 PWA，協助整理 AYP 起步、轉處、升團、同步完成及後續跟進。資料以頁面所列基準整理；**資格、認可、活動要求和表格請以最新官方資料及所屬執行處的確認為準**。

## 功能

- **情況精靈及行動清單**：選擇身份和 AYP 情況，查看下一步；完成項目可在此裝置勾選。
- **進度及日期參考**：分章級記錄服務、技能、康體等進度，按輸入日期作日曆估算。估算不等於符合資格、活動完成、獲批或官方截止日期；各科開始日期、評核及其他條件可能不同。
- **同步方案與銜接參考**：提供試行安排的核對清單。徽章搜尋表是按 2016 年參照資料整理的歷史參考，部分名稱、時數及距離可能過時，不能當作現行要求。
- **表格、評語草稿及查詢**：查找常用表格及官方聯絡資料；評語只提供待填提示，應由導師／評核員根據真實紀錄完成並簽署。
- **中／英切換、鍵盤導覽及離線瀏覽**：首次使用會開啟精靈，也可隨時返回總覽。曾成功載入並安裝快取後，主要內容可離線瀏覽；外部連結及官方文件仍需網絡。

## 資料使用注意

- [童軍通告 P95/2026](https://www.scout.org.hk/uploads/tc/circulars/25989/p095-26.pdf) 指出，正式獲接納前的活動原則上不得用作完成計劃。[AYP 2023 年一般規條](https://ayp.org.hk/wp-content/uploads/2023/09/3.-General-Conditions-Eng_20230911.pdf) 就獲發紀錄簿前三個月內、為參加計劃而進行且符合科目條件的部分活動列出例外。**不能自行假設例外適用**；請向執行處核實現行安排及同步方案適用性。
- 一般起步年齡、13 歲特別安排及漸進章級例外均有條件；一般規條與不同參加途徑亦可能有不同年齡限制。23 歲生日只用作參加計劃的日期參考，不能代替個人資格判斷。活動一般須在 25 歲生日前完成，特殊情況由相關單位考慮。
- 計算器的兩個月倒推以**曆月**估算，並使用獨立輸入的金章科目預計開始日；具體表格、限期及審批時間請向支部組長確認。
- 官方連結、試行細節及舊參照表均可能更新；詳細審查及待核實項目見 [應用審查紀錄](docs/2026-11-04-應用審查.md)。

## 私隱與儲存

待辦、計算器日期與進度、考驗人員資料及開合狀態存於**目前瀏覽器的 localStorage**，不會由本 app 同步至 AYP。瀏覽器阻止儲存時，頁面會提示並只在目前頁面記憶變更。總覽的「清除此裝置的指南資料」會清除上述資料及目前輸入的草稿，保留語言及首次瀏覽設定；亦可在同步方案頁單獨清除考驗人員資料。

清除瀏覽器網站資料、換裝置或使用私密瀏覽，資料可能消失。共用裝置請避免輸入個人資料，使用後清除。本 app 不提供備份、加密或官方紀錄服務。部署環境如啟用 Vercel Web Analytics，可能收集瀏覽統計；前往外部官方網站亦受其私隱政策約束。

## 本機開發與測試

需要 Node.js 及 Python 3；目前 jsdom 開發測試相容 Node.js 22.22.2+（22.x）或 24.15.0+（24.x）。執行期沒有第三方套件；jsdom 只用於開發測試。

```bash
npm install
npm start                 # http://localhost:8000
npm run lint              # 語法及檔案衛生
npm run check             # 引用、雙語及部署體積預算
npm test                  # DOM、互動及 Service Worker 回歸測試
npm run build             # 產生並校驗 dist/
npm run preview           # build 後預覽 dist/
```

瀏覽器回歸測試另外需要 Playwright 及 Chromium：

```bash
npm install --no-save --package-lock=false @playwright/test
npx playwright install chromium
npm start                 # 另一個終端執行
npm run test:full
```

`TEST_BASE_URL` 可指定測試網址。Service Worker、app shell 或快取資產有變更時，應遞增 `sw.js` 的 `CACHE` 版本，並同步更新 `index.html` 三個腳本的 `?v=`。部署使用 `dist/`；部署總量維持 **400 KB** 上限，詳見 [部署規範](docs/部署瘦身與防增肥規範.md)。

## 檔案結構

- `index.html`：頁面結構、響應式樣式與 PWA 載入。
- `data.js`：繁體中文／英文內容及互動工具資料。
- `app.js`：導覽、渲染、計算、儲存及互動。
- `sw.js`、`manifest.webmanifest`：離線快取及安裝設定。
- `analytics.js`：部署環境可用的 Vercel Web Analytics 載入器。
- `tests/`：DOM、行為、離線邏輯及 Playwright 回歸測試。
- `docs/`、`scripts/`：定位、審查、部署規範及建置守門。
