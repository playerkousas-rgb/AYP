# 🎖️ AYP 童軍接駁指南

> **由童軍成員角度出發** —— 搞清童軍進度性獎章 ↔ AYP 嘅同步／直接對應，以及轉執行處、升支部時 AYP 點接駁嘅非官方指南。

## 📌 定位

**非官方輔助網頁（PWA）**，參考 [`upgrade`（童軍準備指南）](https://github.com/playerkousas-rgb/upgrade) 嘅「揀情境→睇點做」＋「升團／接駁」精神。對象係**準備或正在考 AYP 嘅香港童軍成員自己**（童軍／深資／樂行，以及合資格青年領袖）。

reference 用「制服配件升團時可沿用 vs 需購買」做核心；
本 app 用「**童軍進度性獎章 ↔ AYP 同步完成／直接對應**」＋「**轉執行處／升支部時 AYP 進度點帶住走、點接駁**」做核心。

## 🚀 內容

1. AYP 係咩／呢個指南幫到你
2. 資格起步（誰合資格、13 歲安排、點報名）
3. 五科速查（**互動**：揀銅/銀/金即睇要求）
4. **童軍 ↔ AYP 同步完成／直接對應** ★（同步完成方案 2 階段 + 童軍活動直接對應各科）
5. 加入童軍執行處（步驟）
6. **接駁指南** ★（5 個互動情境：轉入童軍 / 升團 / 轉支部 / 級別接駁 / 半路轉處）
7. 幾時起步時間表
8. 完成之後（領獎／證書）
9. 表格＋術語辭典＋FAQ＋常見錯誤＋官方來源

## 🎨 視覺 / PWA

- 三級三色：銅啡 🥉／銀灰 🥈／金黃 🥇（金章相關特別標示）
- 每個情境／詞條可獨立開合，開合狀態 localStorage 記憶
- 自家 LOGO（AYP 獎牌 ＋ 童軍貝登堡意象），深綠 AYP-童軍主題
- 響應式（手機／平板／桌面），可加主畫面、**離線可用**（service worker）

## 🧪 測試

```bash
# 快速（無需瀏覽器，用 jsdom）
npm run test:dom          # 或 node tests/dom-test.js

# 完整（需瀏覽器，先裝 @playwright/test + chromium）
python3 -m http.server 8000 --bind 0.0.0.0   # 終端一
npm install --no-save --package-lock=false @playwright/test
npx playwright install --with-deps chromium
npx playwright test tests/guide.spec.js --workers=1   # 終端二
```
