# 🎖️ AYP 童軍接駁指南 / AYP Scout Bridging Guide

> **情況主導** —— 圍繞童軍成員最常問嘅 5 種「情況」答你：轉入童軍後仲欠咩、兌換、升團接駁、正常流程、其他情況。
> **雙語 Bilingual**：全站支援 繁體中文（香港）／ English，右下角有語言切換掣 🌐，方便由其他執行處（例如國際學校）轉入嘅童軍成員閱讀。

## 📌 定位

**非官方輔助網頁（PWA）**，參考 [`upgrade`（童軍準備指南）](https://github.com/playerkousas-rgb/upgrade) 嘅「揀情況→睇點做」＋「升團／接駁」精神。對象係**準備或正在考 AYP 嘅香港童軍成員自己**（童軍／深資／樂行，以及青年領袖）。

reference 用「制服配件升團時可沿用 vs 需購買」做核心；
本 app 以「**童軍進度性獎章 ↔ AYP 同步完成／直接對應**」＋「**轉執行處／升支部時 AYP 點接駁**」做核心，用**互動揀選**（混合式）呈現。

## 🚀 點樣 5 分鐘用完（新）

- **⚡ 5 分鐘精靈**（置頂第一格）：答 2 條問題（你係邊個＋AYP 去到邊）→ 即出個人「行動卡」：而家位置、建議路線、下一步 3 步（可剔住當待辦清單，會記住進度）、搵邊個、填咩表、需時幾耐
- **🌱 零基礎 3 個 Check**：當你咩都唔知——點查宣誓未、點查有冇已批准支部、點查組長合唔合資格，每張卡都有「照讀對白」俾你問領袖
- **⚡ 30 秒睇懂**：每段開頭一句總結，趕時間睇呢句就夠
- 手機優先：大掣、置頂 5 格＋置底 5 格＋「返頂部」掣，360px 闊都放得下
- **🌐 中／英雙語**：頁面**右上角**浮動掣一撳即切換全站語言（含精靈、行動卡、5 大功能、FAQ、辭典、以下嘅快速工具等），揀嘅語言會記住。國際學校轉入嘅童軍成員可睇 English 版。
- **📱 上 5 下 5 整版 view**：上面一列係情景（⚡精靈／①轉入／②兌換／③升團／⑤其他），下面一列係工具（📋同步方案／🔁兌換表／📝開展表格／🏢查執行處／❓FAQ＋辭典），㩒邊格成版切換。中間預設正常流程：行動卡跟住剔，詳情（零基礎/步驟/時間表/領獎）預設摺埋，開 app 5 分鐘搞掂。
- **🧰 5 個工具整版 view（新）**：每個工具獨立一版，唔使逼喺長頁入面：
  - 📋 **同步方案（試行）**——解釋 2026-08-15 起「項目對項目」對接（並非一對一自動換），須知會執行處支部組長，官方詳情未全公布，附免責聲明
  - 🔁 **單項兌換表（非官方整理）**——我哋自行整理，以官方 2016 年 P103/2016 舊表為底本、剔除 2026-08-15 已取消嘅 8 個專科徽章，方便執行處組長參考，清楚標明「非官方整理，須向執行處組長核實」
  - 📝 **AYP開展表格**——AYP/01 參加申請表等，附官方 PDF 下載連結
  - 🏢 **查執行處／組長**——連結官方「執行處支部組長名單」PDF、AYP 聯絡我們頁、各地域辦事處電話
  - ❓ **FAQ＋術語辭典**——常見問題＋術語解釋，查嘢唔使估

## 🚀 5 大核心功能（詳細版）

**① 由其他執行處轉入童軍 → 仲有咩要考**（互動）
- 揀「章級（銅/銀/金）」＋「剔已喺原執行處批核嘅科」→ 即時出「轉入童軍後仲欠邊科」＋ 每科可以點用童軍活動補返
- 附轉入行政手續卡（FORM AYP/09 等）

**② 兌換情況**
- 成個章兌換（同步完成方案，兩階段）
- 單科對應參考表（童軍活動/徽章 → AYP 服務/技能/康體/野外/團體生活科；標明需核實）

**③ 邊個支部考到咩・升團後要點做**
- 童軍 → 深資 → 樂行 階段圖，逐格：可考咩、同步/對應、升團後點跟進

**④ 各支部正常開始 AYP 流程**
- 通用步驟（迎新講座→FORM AYP/01→紀錄簿）＋ 各支部可考咩

**⑤ 其他可能情況**
- 已喺其他處考完低級先轉入 (B)
- 未夠 14 歲／幼童軍升童軍 鋪路 (D)
- 青年領袖直入金章 (E)
- 海外／國際 AYP 轉入香港童軍 (F)
- 轉處時紀錄唔齊／紀錄簿問題 (G)
- 轉處時通用手續
- 反方向：由童軍轉返學校 (A)
- 用學校／其他處活動補 AYP 時數 (C)

**配套資源**：幾時起步時間表、常用表格一覽、術語辭典、FAQ、完成之後領獎。

## 📂 檔案結構

```
AYP/
├── index.html            (主頁：5 大功能區塊 + 內嵌 CSS，DOM 全用 id 俾雙語替換文字)
├── data.js               (雙語資料庫 LOCALES = { "zh-HK": {...}, "en": {...} }：轉入/兌換/升團/流程/其他情況/資源)
├── app.js                (主程式：語言切換 setLang()、互動決策、開合狀態、渲染)
├── manifest.webmanifest  (PWA)
├── sw.js                 (Service Worker)
├── package.json
├── docs/定位規格.md
├── assets/               (logo 各尺寸)
└── tests/
    ├── dom-test.js       (jsdom 快速 DOM 測試，60 項)
    └── guide.spec.js     (Playwright 回歸測試)
```

## 🧪 測試

```bash
# 快速（無需瀏覽器，用 jsdom）
npm run test:dom          # 或 node tests/dom-test.js

# 完整（需瀏覽器）
python3 -m http.server 8000 --bind 0.0.0.0
npm install --no-save --package-lock=false @playwright/test
npx playwright install --with-deps chromium
npx playwright test tests/guide.spec.js --workers=1
```
